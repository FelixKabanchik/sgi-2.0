# SGI 2.0 - Sistema de Gestión de Inventario

## Descripción del Proyecto
Sistema informático desarrollado en Python para centralizar la gestión operativa de un comercio. Permite el control preciso y automatizado de productos, categorías e inventario.

## Funcionalidades Principales
- Control de acceso (Login)
- ABM de Productos, Categorías e Inventario, con validación de duplicados por nombre
- Ordenamiento con listas paralelas (reemplaza los algoritmos individuales de burbuja, selección e inserción)
- Búsquedas secuencial y binaria de productos
- Validaciones con expresiones regulares (nombres y códigos)
- Consultas y reportes con funciones de orden superior (map, filter y reduce) y funciones lambda
- Búsqueda de productos por palabras clave y generación de etiquetas
- Gestión completa con Git
